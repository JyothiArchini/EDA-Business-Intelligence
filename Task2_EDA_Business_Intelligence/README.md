# Exploratory Data Analysis & Business Intelligence

## Overview
This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to identify business trends and insights.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- Google Slides

## Project Tasks
- Data Loading and Cleaning
- Descriptive Statistics
- Univariate Analysis
- SQL Business Queries
- Correlation Analysis
- Dashboard Creation

## Key Insights
- Sales and Profit are positively correlated.
- Higher discounts negatively impact profit.
- West region generated the highest sales.
- Technology category performed strongly.
